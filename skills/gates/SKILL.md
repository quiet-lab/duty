Навык работает, только если в конфигурации есть раздел `[bitbucket]`
(для `now` — `[jenkins]`); иначе сценарий печатает одну строку об этом, и
навык заканчивается.

Переданные аргументы вызова (подставлены при запуске, пустая строка —
аргументов нет): «$ARGUMENTS».

Допустимые значения: пусто — таблица pull request'ов; `now` — что идёт
на узлах Jenkins и чем заняты агенты.

Первое и единственное действие — одна
команда, ветвление по аргументу делает сам сценарий (слово now — режим
now, иначе таблица pull request'ов):

```sh
python3 -I "${CLAUDE_PLUGIN_ROOT}/scripts/gates.py" '$ARGUMENTS'
```

Если аргумент — слово now, вывод — две таблицы (описаны в первом разделе
ниже); основная таблица не строится, Bitbucket не опрашивается, разделы
«Шаги» и «Итог» пропускаются. Иначе вывод — таблица pull request'ов,
дальше «Шаги» и «Итог».

## Режим now (аргумент — слово now)

При аргументе now выполнить только этот раздел: основная
таблица pull request'ов не строится, Bitbucket не опрашивается, разделы
«Шаги» и «Итог» ниже пропускаются. Вернуть вывод команды выше без
изменений в ячейках, фильтр не применять.

Вывод — две таблицы: «Исполнители Jenkins» (узел, состояние, задание
и сборка, сколько идёт, кто запустил; последняя строка — очередь
ожидания) и «Агенты, сессии и занятость на станции» (сессии Claude Code
с именем, каталогом, статусом, временем работы; агенты herdr; отметки
реестра занятости). Готово, если обе таблицы напечатаны. «Решения
за пользователем» — отметки занятости с пометкой «устарела» (снять
может только держатель или пользователь); «Что не проверено» — строка
«Не проверено: …» под таблицами и недоступный Jenkins.

## Основное задание (аргумент не now)

Цель: одна таблица открытых pull request'ов пользователя
(`bitbucket.user`) во всех репозиториях Bitbucket. Только чтение.

Вход: аргумент навыка — необязательный фильтр (подстрока репозитория,
ветви или номер тикета по образцу `jira.ticket`); пусто — все.

## Шаги

1. Команда выше уже выполнена; повторно не запускать. Готово, если вывод — таблица Markdown и строка «Всего открытых: N».
   Строка «ОСТАНОВКА: Bitbucket ответил 401/403» — повторять нельзя:
   итог из одной строки об этом и раздел «Что не проверено».
2. Если аргумент не пуст — оставить строки, где он встречается.
   Больше ничего не запрашивать: сценарий уже прочитал статусы сборок,
   `wfapi/describe` и `…/merge`.

## Итог

По `${CLAUDE_PLUGIN_ROOT}/reference/report.md`: таблица из вывода
сценария без изменений в ячейках; «Решения за пользователем» — pull
request'ы с «можно» в колонке «Слияние» (слияние решает пользователь)
и с «конфликт»; «Что не проверено» — сборки с пометкой «недоступна».
Комментариев к таблице не писать.

Запрещено: запускать задания Jenkins, сливать, комментировать pull
request'ы, повторять запросы после 401/403.
