Цель: решить, какие задачи можно раздать субагентам прямо сейчас,
не загружая основную сессию сырыми фактами. Только чтение.

Переданные аргументы вызова (подставлены при запуске, пустая строка —
аргументов нет): «$ARGUMENTS».

Допустимые значения: необязательный фокус; при нём в таблицу попадают
только задачи, где он встречается, и всё, что с ними пересекается.

Корень монорепозитория — `${CLAUDE_PROJECT_DIR}`; раскладка
и защищённые ветви — `${CLAUDE_PLUGIN_ROOT}/README.md`, раздел «Раскладка».

## Шаги

1. Собрать факты одной командой:

   ```sh
   bash "${CLAUDE_PLUGIN_ROOT}/scripts/facts.sh" "${CLAUDE_PROJECT_DIR}"
   ```

   Готово, если в выводе есть все разделы: «Деревья», «Worktree
   сабмодулей», «Свои ветви в origin», «Открытые pull request'ы»,
   «Jenkins», «Машина», «Занятость», «Вопросы агентов без ответа»,
   «Текущая работа», «Открытые задачи OpenSpec», «Отложенные вопросы»,
   «Jira», «Неделя в цифрах». Пропавший раздел — в «Что
   не проверено», без повторного запуска всего сценария.
2. Дочитать только нужное для решения, не больше трёх файлов: подраздел
   «Следующие шаги» `todo.local.md`, `tasks.md` изменения из фокуса,
   файл отложенного вопроса, у которого по таблице условие пересмотра
   могло наступить (сверить условие с фактами шага 1). Вывод резать `head -60`.
3. Составить задачи. Источники: «Следующие шаги» снимка, открытые задачи
   OpenSpec, pull request'ы с упавшими воротами, ветви без pull
   request'а, вопросы с наступившим условием пересмотра, тикеты в работе.
   Одна задача — одна строка, дубли из разных источников сливаются.
4. Для каждой задачи определить:
   - что трогает: репозитории (пути сабмодулей), экземпляры стенда,
     домены студии, узлы Jenkins (`HeavyCI_1`, `QMS_DEV`, `QMS_PROD`,
     `QMS_FEATURE`);
   - с чем пересекается: другая задача с тем же репозиторием и ветвью,
     тем же узлом или стендом, грязное дерево, занятый исполнитель;
   - модель — по лесенке `${CLAUDE_PLUGIN_ROOT}/skills/dispatch/SKILL.md`,
     раздел «Модель»; сомнение — в пользу дешёвой;
   - можно ли сейчас: «да» или «нет» с причиной — ждёт решения
     пользователя (в том числе вопрос агента без ответа), ресурс реестра
     занят живым держателем по разделу «Занятость» и другого экземпляра
     или домена нет (ответ «нет: занят <ресурс> держателем <имя>»), занят
     узел, грязное дерево, нагрузка за минуту
     (`/proc/loadavg`) не ниже числа ядер, доступной памяти меньше
     четверти, зависит от другой задачи.
5. Перечень «Уборка»: до пяти пунктов — что освободит место или
   исполнителей (слитые ветви с worktree, зависшие в очереди сборки,
   крупные каталоги `/tmp`), каждый со ссылкой на `/duty:cleanup`
   или на команду. Отметки реестра занятости без живого держателя (столбец «pid жив»
   — «нет») — пункт перечня; снимает их главная сессия командой
   `busy.py release <ресурс> --force`, навык их не трогает.

## Итог

По `${CLAUDE_PLUGIN_ROOT}/reference/report.md`. Таблица «Задачи»:

| Задача | Источник | Что трогает | С чем пересекается | Модель | Можно сейчас |

Затем «Уборка» (короткий перечень), «Решения за пользователем»
(вопросы агентов без ответа — по строке: символ, задача, номер, суть),
таблица «Неделя в цифрах» из раздела `facts.sh` без изменений и выводов
(порогов нет), «Что не проверено». Не больше 15 строк в таблице задач;
сверх — одной строкой «ещё N задач: …».

Запрещено: любые изменения в деревьях и внешних системах, `git fetch`,
запуск заданий и прогонов, чтение деревьев целиком.
