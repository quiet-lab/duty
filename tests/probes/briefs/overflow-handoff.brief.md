# Проба overflow-handoff

## Цель

Проверить передачу работы при переполнении контекста: раздел «Передача», `state.md`, завершение с пометкой «передача», открытый workspace; затем продолжение вторым запуском.

## Критерий готовности

Все шаги раздела «Следующие шаги» выполнены, команды раздела «Команды проверки» дают ожидаемое, итоговый отчёт есть: `test -s "$DUTY_TASK/report.md"`.

## Условие остановки

Шаг не выполняется или проверка падает и не чинится правкой за один подход — остановка и запись причины в `report.md`; вопрос вне пробы не задаётся.

## Следующие шаги

1. Занять и освободить ресурс: `python3 -I {{PLUGIN}}/scripts/busy.py claim dev-stand-99 --holder <метка> --task "$DUTY_TASK" --pid "$PPID" --note 'проба 06'`, затем `python3 -I {{PLUGIN}}/scripts/busy.py release dev-stand-99 --holder <метка>`. Метка workspace — в служебном блоке этого файла. После шага 1 по правилам задачи контекст считается переполненным: перейти к «Передача» (раздел «Переполнение контекста» агента), шаг 2 не выполнять.
2. Записать файл `$DUTY_TASK/second-step.txt` со строкой «второй шаг выполнен». Его выполняет продолжение, не первая половина.

## Команды проверки

- `ls $DUTY_TASK/second-step.txt` — после продолжения файл есть, до него нет.
- `python3 -I {{PLUGIN}}/scripts/busy.py list` — отметок `dev-stand-99` этой пробы нет.

## Принятые решения

- репозиторий проекта не трогать; Jira, Bitbucket, Confluence, Jenkins не менять; push только в песочный `origin` (`{{SANDBOX}}/origin.git`), если разрешён ниже.
- Песочница `{{SANDBOX}}/` вне проекта: правки только в клонах внутри `$DUTY_TASK/work/`.
- Тесты песочницы: `{{SANDBOX}}/venv/bin/python -m pytest -q` (в системном `python3` pytest нет). Один тест падает намеренно: `tests/test_pricing.py::test_threshold_is_inclusive`.
- Вопросов не задавать (`ask.py` не вызывать).
- Workspace при передаче не закрывать (правила задачи); после продолжения — закрыть.

## Ожидание в report.md

Первая половина: в `brief.md` раздел «Передача», `state.md` с шагом 2 следующим, `report.md` с пометкой «передача», workspace открыт. Вторая половина (продолжение): `second-step.txt` записан, `report.md` перезаписан итогом, workspace закрыт.

## Завершение

По окончании выполнить раздел «Завершение» агента `duty:worker` целиком: снять отметки реестра, закрыть свои вкладки, записать `report.md` и последний `state.md`, `SendMessage` главной сессии (три строки и путь к `report.md`), уведомление herdr (`herdr notification show`), и закрыть workspace (`herdr workspace close "$HERDR_WORKSPACE_ID"`), если правила не велят иного.
