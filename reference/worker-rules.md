# Правила задачи {{NAME}}

Агент `duty:worker` перечитывает этот файл перед каждым внешним
действием. Главная сессия дописывает раздел «Переданные» по ходу работы;
запись там отменяет разрешение из `brief.md`.

Запреты этого файла принадлежат плагину; остальное названо ссылкой
на файл-владелец. `<плагин>` — каталог плагина из служебного блока
`brief.md`, `CLAUDE.md` — файл монорепозитория.

## Общие запреты монорепозитория

- Правила `CLAUDE.md`, `.claude/rules/` и `~/.claude/CLAUDE.md` действуют
  целиком.
- `todo.local.md`, навыки `/handoff` и `/sync-parents` — у главной сессии,
  здесь не выполняются.
- Главный checkout монорепозитория и сабмодулей не правится: работа —
  в своих worktree и ветвях, названных в `brief.md`.
- Защищённые и именные ветви — `CLAUDE.md`, «Ветви»; признак именной ветви —
  `<плагин>/README.md`, «Раскладка».
- Индекс и `git stash` — `CLAUDE.md`, «Субагенты в одном репозитории»;
  `git add -A`, `git add -u`, `git stash` отвергает хук forbid (`<плагин>/hooks/forbid.py`).
- Push ветвей задачи как копий и pull request — `~/.claude/CLAUDE.md`,
  «Ветви, pull request'ы и конвейер»: push разрешён, пока его не запретят
  «Переданные», pull request записка не разрешает.
- Запуск на Jenkins — тот же раздел: долгое задача не запускает; работа
  с узлом и короткие прогоны — по разрешению записки.
- Слияние, выкат, записи в Jira, Bitbucket и Confluence — только если они
  явно разрешены в `brief.md` или ниже; иначе — вопрос
  (`<плагин>/agents/worker.md`, п. 5). Исключение — тикет по правилу ревью.
- Записка не сужает общие правила; чтение документов исполнителем
  и противоречие записанному — `~/.claude/CLAUDE.md`, «Постановка задачи».
- Вопросы и условие остановки — `<плагин>/agents/worker.md`, п. 5.
- Падения тестов — `~/.claude/CLAUDE.md`, «Починка падающего набора тестов»;
  доводка оснастки — там же, «Оснастка тестов».
- Изоляция — `docs/isolation.md`; ресурсы реестра занятости —
  `<плагин>/README.md`, «Реестр занятости», порядок — `<плагин>/agents/worker.md`,
  п. 6. Чужие экземпляры стенда, узлы и домены студии не трогать.
- Параллельность — `~/.claude/CLAUDE.md`, «Постановка задачи»; нагрузка
  и завершение процессов — там же, «Субагенты».
- Таймеры и опрос — `~/.claude/CLAUDE.md`, «Устройство кода». Ожидание —
  по событию: файл `done` вкладки, `herdr pane wait-output`, inotify;
  условие другой задачи — `<плагин>/agents/worker.md`, п. 7.
- Ожидание внутри хода и вкладки команд — `<плагин>/agents/worker.md`,
  п. 3 и 4; вкладка открывается только через `scripts/tab-run.sh` (`herdr tab
  create`, `pane run`, `pane send` отвергает хук forbid).
- Туннель и сеть станции не переключаются (`nmcli`, `awg`, `amn-*`, `wg`,
  `openvpn`, `resolvectl`, `ip link set up/down`); push с `--force` и в `dev`,
  `dev2`, `master`, пароль литералом в `curl -u` и `sshpass -p`, чтение
  `~/.config/axata/*` и печать окружения или секретных переменных запрещены;
  пароли и токены — только из файлов через `set -a` и stdin, в вывод не
  попадают (проверяет хук forbid, `<плагин>/hooks/forbid.py`).
- Права root — `~/.claude/CLAUDE.md`, «Повышение привилегий».
- `/tmp` — `CLAUDE.md`, «Субагенты в одном репозитории»: выводы и копии
  деревьев — в каталог задачи.
- Ревью и Fable на ревью — `.claude/rules/code-review.md`; прямое указание
  пользователя записывается в «Переданные». Раздел отчёта —
  `<плагин>/reference/report.md`, п. 4.
- Сравнение снимков экрана — `~/.claude/CLAUDE.md`, «Ветви, pull request'ы
  и конвейер»: снимки и перечень несовпадений — в `screenshots/` каталога
  задачи, допустимость решает пользователь по вопросу `ask.py`.
- Модели субагентов — `~/.claude/CLAUDE.md`, «Субагенты»; лесенка —
  `<плагин>/skills/dispatch/SKILL.md`, «Модель»; форма в отчёте —
  `<плагин>/reference/report.md`, п. 3.
